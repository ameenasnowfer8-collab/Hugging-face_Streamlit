# Smart AI Question Answer

## Project Overview

Smart AI Question Answer is a simple AI-powered web application built using Python and Streamlit. It allows users to enter questions and receive answers generated by an AI language model.

The application uses Hugging Face Inference API and the Google Gemma model to generate answers.

## Live Link:
[https://hugging-faceapp-a69ahsymg3kdfsbucfvlm2.streamlit.app/]

## Features

* Simple and user-friendly interface
* Enter questions using a text box
* AI-generated answers
* Clean and light gradient UI
* Uses Hugging Face Inference API
* Built with Streamlit
* Secure API token using Streamlit secrets

## Technologies Used

* Python
* Streamlit
* Hugging Face Hub
* Google Gemma 3 4B IT
* HTML and CSS

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/ameenasnowfer8-collab/Hugging-face_Streamlit.git
```

### 2. Open the Project Folder

```bash
cd Hugging face
```

### 3. Install the Required Libraries

```bash
pip install -r requirements.txt
```

If pip does not work, use:

```bash
python -m pip install -r requirements.txt
```

## Hugging Face API Token

Create a Hugging Face access token and add it to Streamlit secrets.

Create the following file:

```text
.streamlit/secrets.toml
```

Add:

```toml
Access_Token = "your_huggingface_token"
```

## Run the Application

Run the following command in the terminal:

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## How It Works

1. The user enters a question.
2. Streamlit receives the question.
3. The question is sent to the Hugging Face Inference API.
4. The Google Gemma model processes the question.
5. The generated answer is displayed on the webpage.

## Model Used

```text
google/gemma-3-4b-it
```

The model is used through the Hugging Face Inference API.
